OutcomeThe queue stopped aging. I review one report instead of opening thirty tickets.

The reason is evidenced

Each open account carries one of 13 blocker categories plus the customer's verbatim sentence and a link to the thread. Four accounts, four completely different next actions.

Two of these shouldn't be chased

The unapplied credit is our cash-application task, so it has no follow-up button at all. The blocked PO already has a draft, locked so the customer can't be chased twice.

The follow-up is gated

The tool proposes the next step and the date it's due — it never executes it. A follow-up draft exists only when I press the button, and the button then disables itself.

How I build

Four steps that repeat

01
Map the manual process first. Write down how the job is done today, with no AI — naming the decision made at each step.
02
Decide where AI belongs. "Copy A into B" is plain automation. "Read, classify, decide, write" is where a model earns its place.
03
Build the human gate in from the start. The result stops for approval before it reaches a customer — never bolted on afterwards.
04
Turn every correction into a written rule — with the real case attached. The tools get more correct with use instead of decaying.

Two of the five outgrew being a single procedure. The moment I needed to know what happened last month, a stateless tool wasn't enough — so they became systems where one stage writes a ledger another reads a month later.

Governance

Where the AI has to stop

✋
Nothing customer-facing sends itself. Every email, invoice and ticket resolution waits for a human.
🚫
Never chase a credit balance. Net-negative accounts are excluded regardless of status.
✍️
Never invent commentary. A new account shows an empty cell. Blank is the honest answer.
🙋
Never guess a classification. Unknown owner means the run pauses and asks me.
📉
Never report a number it can't prove. Failed reconciliations and implausible source reads abort the report.

"A tool that stops and asks is worth more than one that's confidently wrong."
